# Convite de formatura

Convite de formatura interativo feito em HTML, CSS e JavaScript puros, publicado no GitHub Pages.

**Ver online:** https://hitaloyo.github.io/convite-formatura-web/completo.html

## Como funciona

Cada convidado recebe o link da versão que corresponde às cerimônias para as quais foi convidado:

| Página | Conteúdo |
| --- | --- |
| `completo.html` | Todas as cerimônias |
| `colacao.html` | Colação de grau |
| `culto.html` · `missa.html` | Culto ou missa |
| `culto_colacao.html` · `missa_colacao.html` | Culto ou missa com a colação |

Ao abrir, um aviso pergunta se o convidado quer ouvir a música de fundo (navegadores bloqueiam áudio que começa sozinho), e um botão permite ligar e desligar o som depois. O layout se adapta ao celular.

## Como rodar

Não precisa de build: abra qualquer página `.html` no navegador.
